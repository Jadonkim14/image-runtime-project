# V0.1 — Existing System Execution

## 목표

기존 OpenVINO 이미지 분류 프로그램을 수정하지 않고 실행한 뒤, 전체 처리 흐름을 이해한다.

이 단계에서는 성능 최적화, Thread, Pipeline, Scheduler 등을 추가하지 않는다.

## 주요 확인 내용

### Tensor

이미지 픽셀 데이터를 OpenVINO 모델이 사용할 수 있는 다차원 배열 형태로 전달한다.

```text
img.mat_data
    ↓
OpenVINO Tensor
```

### Synchronous Inference

```c
ov_infer_request_infer(infer_request);
```

Inference가 끝날 때까지 현재 실행 흐름이 대기한다.

현재 baseline에는 Thread Pool, Async Queue, Pipeline, Scheduler가 없다.

### 결과 처리

Output Tensor의 float 값을:

```c
results[i].probability = float_data[i];
```

형태로 저장한 뒤 `qsort()`로 큰 값부터 정렬한다.

현재 출력되는 `probability` 값은 별도 Softmax 처리를 하지 않으므로 실제 확률이라기보다 모델의 raw output score로 이해하는 것이 적절하다.

## 헷갈렸던 부분 정리

* `mkdir -p`의 `-p`는 상위 디렉터리까지 함께 만들고, 이미 존재해도 에러를 내지 않는다.
* Tensor는 모델 입력으로 사용하는 다차원 숫자 배열이다. 이미지 픽셀 데이터가 Tensor 형태로 OpenVINO에 전달된다.
* `qsort()` 비교 함수에서 `return -1`은 첫 번째 값을 앞으로, `return 1`은 뒤로 보낸다는 의미이다.
